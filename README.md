## 🎯 Sobre o Portfólio
Este repositório centraliza toda a minha jornada e evolução na garantia de qualidade de software (QA). Abaixo estão listados de forma organizada todos os meus **21 projetos práticos**, cobrindo desde automações complexas com pipelines CI/CD até testes exploratórios manuais em cenários reais.

---

## 🛠️ Habilidades Técnicas (Skills)

*   **Testes Automatizados:** Automação Web (Cypress e Playwright), Testes de API, Testes de Banco de Dados.
*   **DevSecOps & CI/CD:** Criação de pipelines automatizadas via GitHub Actions (DAST, API e Web).
*   **Testes Manuais:** Testes Funcionais, Exploratórios, de Regressão, Usabilidade e Escrita de Casos de Teste.
*   **Banco de Dados:** Validação de dados, consultas estruturadas e manipulação com MySQL.
